# ImpactLab Evidence Gap Capture Sheet

FILMA · ImpactLab Requirement Session. A single-page form for table groups to capture three evidence gaps each, with a live reporting-prompt sentence per gap.

Open `index.html` in a browser. No build step.

- **Fill the sheet**: drafts autosave in the browser (localStorage).
- **Download CSV** / **Copy as text**: work anywhere, so groups can send their sheet to the facilitator.
- **Submit sheet** and **Compile submissions** use the shared database of the Claude artifact version and are not available when the page is opened from this repo or GitHub Pages.
